# Abstract

Student academic performance prediction is an important application of supervised machine learning because it can help teachers and institutions identify learners who may require additional academic support. This project, titled **Student Pass/Fail Prediction Using Machine Learning**, develops a working prediction system that classifies a student as likely to pass or fail based on three academic indicators: attendance percentage, internal marks, and test/exam score.

The dataset used in this project is generated synthetically with a reproducible random seed and contains realistic variation across student records. Each record includes student ID, student name, attendance, internal marks, test score, and final result. The result is produced using a transparent academic scoring rule with added noise, so the model learns from meaningful patterns rather than from duplicated or hardcoded data.

The machine learning workflow includes dataset generation, missing value checking, duplicate removal, data type validation, feature selection, target encoding, train/test splitting, model training, and model evaluation. Two classification algorithms are trained and compared: Logistic Regression and Decision Tree Classifier. The models are evaluated using accuracy, precision, recall, F1 score, confusion matrix, and classification report. The selected model is saved as `best_model.pkl` and is used by the prediction module and Streamlit web application.

The final system provides a professional dashboard for viewing dataset statistics, making individual student predictions, filtering dataset records, reviewing model performance, and analyzing feature distributions. After training, the Decision Tree Classifier was selected as the best model because it achieved the strongest F1 score on the test set. The selected model achieved an accuracy of 88.46% and an F1 score of 91.71%. The system is useful as a demonstration of how machine learning can support early academic intervention, while also showing the complete flow from data preparation to a usable local application.
